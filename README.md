# Advanced Data Analytics (SQL)

SQL analytics on a retail sales dataset (gold.fact_sales, gold.dim_customers, gold.dim_products) using CTEs, window functions, and views to uncover trends and 
segment customers and products.

## Files
exploratory_data_analysis.sql — Initial data exploration: key metrics, segmentation by country/gender/category, and top/bottom products and customers by revenue.

advanced_analysis.sql — Deeper analysis: sales trends over time, running totals, year-over-year product performance, customer/product segmentation, and 
two reporting views (gold.report_customers, gold.report_products) with KPIs like recency and average order value.

## Skills
Joins, CTEs, window functions (RANK, LAG, AVG() OVER), CASE-based segmentation, and SQL views.
